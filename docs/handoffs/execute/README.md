# Open briefs

Each brief here holds its own state in frontmatter, and no file lists the
queue. [CLAUDE.md](../../../CLAUDE.md) § "Handoff briefs" has the keys,
the lifecycle and the command that prints the queue; this file says what
the briefs here are for.

## Direction: both

Briefs arrive both ways. Most are triaged from notes that sessions in
other repos leave in the private inbox, `~/handoff-inbox/fabric-tools/`,
as the first one was. A session here writes one directly when its own
work will outlive it.

## Public means scrubbed

This repo is public, so a brief is published when it is pushed, and a
push cannot be taken back. A note in the inbox may be raw; a brief may
not. Cite client material by kind and date, as in "a client estate's
generator, 2026-09-30", and never by name: no client, item, workspace,
function or column names, no paths, ids, commits, branches or pull
requests. identity-guard blocks only the strings on its list, so the
author's scrub is the check, not the hook, and each brief says under
*Scrubbing* what it left out.

## Not the whole backlog

These briefs are the triaged backlog only. Notes in the inbox wait there
for the user's word, untriaged, and the status command lists them when
run without `--no-inbox`. A note becomes a brief, or is folded straight
into the work, when the user asks for it; it then leaves the inbox only
with the user's yes.
